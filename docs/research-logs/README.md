Start with the [domain specification](2026-10-11-knowledge-design-skills-new-project-bootstrap-process.md), [execution contract](2026-10-11-bootstrap-execution-contract.md) and [research tooling](2026-10-11-bootstrap-research-tooling.md).

Persist domain decisions, source selection, direct examination, research challenges, workflow design, skill boundaries, pack research, progressive examples and evaluation evidence here.

Use the stage filenames in the domain specification. Pack records belong under `packs/<pack-id>/` when that work starts. Each record states its status, decisions, limitations, output paths and verification evidence.

All S00–S19 stages are initially PLANNED. This archive supplies bootstrap inputs, not accepted stage results. The first execution creates `s00-workspace.md` after verifying the actual repository.

On resume, read accepted records and inspect their outputs. Conversation history, filenames and commit subjects alone do not establish completion.

Keep meaning preservation, internal clarity, factual support and human comprehension results separate. Record tests as NOT_RUN until executed. Supplied books and private source material remain outside tracked files.
